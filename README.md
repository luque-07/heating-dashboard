# Heating Dashboard

Dashboard de consumo estimado de calefacción a partir de
previsiones meteorológicas.

## Objetivo

Obtener temperaturas medias diarias, calcular el consumo
estimado de calefacción, guardar los resultados en CSV y
generar un dashboard web con Apache ECharts.

## Tecnologías

- Python
- Open-Meteo API
- CSV
- HTML y JavaScript
- Apache ECharts
- Git y GitHub
